# UpliftEd Project Summary — Hackathon September 2025

## Problem Statement
In online education, learners encounter critical operational barriers:
1. **Language Exclusion**: Non-native English speakers struggle to follow technical lectures.
2. **Classroom Safety Risks**: Remote virtual classrooms lack automated real-time moderation against harassment or hostile behavior.
3. **Quality Learning Gap**: Learners in underserved areas require structured micro-credentials with downloadable offline lecture notes and financial aid support.

---

## Solution Overview: UpliftEd
An AI-powered, multilingual virtual learning platform that unifies real-time voice translation, computer vision classroom safety, and structured micro-courses.

### Key Features Implemented:
* **Microphone Speech Translation and Voice Synthesizer**: Translates English microphone speech into Tamil (`ta`), Telugu (`te`), Hindi (`hi`), Spanish (`es`), French (`fr`), and German (`de`) with speech synthesis audio playback.
* **YOLOv8 AI Safety and Moderation Guard**: Monitors video streams using object detection and expression analysis, featuring automatic emergency call termination and incident report filing.
* **NPTEL-Style Micro-Courses**: Interactive video player, downloadable chapter notes (`.txt`), self-assessment quizzes, and digital skill badges.
* **Automatic AI Lecture Notes**: Real-time timestamped note extraction from live speech.
* **Detailed Analytics and Scholarship Portal**: Student performance dashboard and grant application workflows.
* **Secure Dual-Layer Database**: PHP MySQL backend + persistent client session store.
